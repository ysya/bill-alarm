# 核心功能 UX 重整 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 依 `docs/superpowers/specs/2026-08-11-core-ux-design.md`（含 §0 Codex 修訂）：總覽改單一待辦流＋可點 summary 卡、一鍵已繳＋Undo 全入口統一、掃描邏輯收斂、帳單列表 tabs 重整、詳情頁單一狀態路徑、銀行帳戶區降級、導覽四格。

**Architecture:** 伺服器先行（list unpaid＋排序、summary 語意），再抽兩個共用 composable（useMarkPaid／useScanTrigger），最後由內而外改頁面（總覽 → 列表 → 詳情 → 銀行/導覽）。

**Tech Stack:** Hono + zod、Prisma、Nuxt 4 + shadcn-vue、vue-sonner、vitest。

## Global Constraints

- 文案 zh-TW；程式碼與 commit 英文（conventional commits）。
- 一鍵已繳 toast：`duration: 8000`、文字「已標記 {銀行} 已繳（繳費日：今天）」、description「點復原可撤銷；改日期請到帳單詳情」、action「復原」。
- autoDebit 帳單按鈕文字「確認已扣款」；一般「已繳」；按鈕 `aria-label` 含銀行名。
- tabs 合法值 `all|unpaid|paid|no_payment`；非法 `?tab=` 落回 `all`。
- 排序：unpaid＝`dueDate asc`；其餘維持現行 `[{billingPeriod desc},{dueDate desc}]`（paid 保留帳期分組——偏離 spec §0「paidAt 降冪」，理由：帳期分組＋月小計對帳單場景更有用，最新帳期本來就在最上；T8 會把此偏離同步回 spec）。
- 已確認事實：`markAsPaid(id, paidAt?)` 走 `/pay`，本就支援自訂日期且對已繳帳單可重寫日期；`useScanEvents` 為 per-component 實例，無互踩問題，spec §3 的「多訂閱」改動**不做**（T8 同步 spec）。
- 測試指令：`pnpm --filter @bill-alarm/server test`；web：`pnpm --filter @bill-alarm/web lint`＋`pnpm typecheck`＋`pnpm build`。

```ts
import { toast } from 'vue-sonner'

/** One-tap mark-paid with an Undo toast — the single implementation every
 *  entry point (dashboard, list, detail) shares. paidAt is always "today";
 *  backdating lives in the bill-detail edit mode. */
export function useMarkPaid() {
  const { markAsPaid, unpay } = useBillApi()
  const markingIds = ref<Set<string>>(new Set())

  async function markPaid(bill: { id: string, bank?: { name: string } | null }, onChanged: () => void) {
    if (markingIds.value.has(bill.id)) return
    markingIds.value.add(bill.id)
    const bankName = bill.bank?.name ?? '帳單'
    try {
      await markAsPaid(bill.id)
      onChanged()
      toast.success(`已標記 ${bankName} 已繳（繳費日：今天）`, {
        duration: 8000,
        description: '點「復原」可撤銷；要改繳費日請到帳單詳情。',
        action: {
          label: '復原',
          onClick: async () => {
            try {
              await unpay(bill.id)
              toast.success(`已復原 ${bankName} 為待繳`)
            }
            catch (e) {
              toast.error('復原失敗', { description: String(e) })
            }
            finally {
              onChanged() // 失敗也刷新，讓畫面回到伺服器真實狀態
            }
          },
        },
      })
    }
    catch (e) {
      toast.error('操作失敗', { description: String(e) })
    }
    finally {
      markingIds.value.delete(bill.id)
    }
  }

  return { markingIds, markPaid }
}
```

- [ ] **Step 2: useScanTrigger.ts**（自 ScanCard.vue 的 handleScan 原樣搬移，簽名如上；`onDone` 於 finally 呼叫）

```ts
import { toast } from 'vue-sonner'

/** Single source of truth for manual scan triggering + result toasts. */
export function useScanTrigger() {
  const settingsApi = useSettingsApi()
  const scanning = ref(false)

  async function triggerScan(onDone?: () => void) {
    scanning.value = true
    try {
      const result = await settingsApi.triggerScan()
      const errorCount = result.errors?.length ?? 0
      const firstReason = result.errors?.[0]?.reason
      const summary = `掃描 ${result.scanned} 封郵件，發現 ${result.newBills} 筆新帳單${errorCount > 0 ? `，${errorCount} 個錯誤` : ''}。`
      const desc = errorCount > 0 && firstReason ? `${summary}\n首個錯誤：${firstReason}` : summary
      const action = { label: '查看紀錄', onClick: () => navigateTo('/scan-logs') }
      if (errorCount > 0) toast.warning('郵件掃描完成（有錯誤）', { description: desc, action })
      else toast.success('郵件掃描完成', { description: desc, action })
    }
    catch (e) {
      console.error('[scan] failed:', e)
      const status = (e as { response?: { status?: number } })?.response?.status
      const desc = status === 404
        ? '掃描端點不存在 (HTTP 404) — 請強制重整網頁或確認 server 已更新到最新版本'
        : status
          ? `HTTP ${status}：${(e as Error).message}`
          : String(e)
      toast.error('掃描失敗', { description: desc })
    }
    finally {
      scanning.value = false
      onDone?.()
    }
  }

  return { scanning, triggerScan }
}
```
